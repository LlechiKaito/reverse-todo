# 逆Todo - 機能アイデア整理

「やめたいことを止めるためのアプリ」

## コア機能（必須級）

| 機能 | 説明 |
|------|------|
| **やめたいこと登録** | 「夜食」「SNSの見すぎ」「喫煙」など、やめたい習慣を登録 |
| **連続日数（ストリーク）** | 我慢できている連続日数を自動カウント |
| **挫折の記録** | 負けてしまった時に「挫折」ボタンを押してリセット |

## あると良さそうな機能

| 機能 | 説明 |
|------|------|
| **やめたい理由の記録** | なぜやめたいか（動機）をメモしておける |
| **挫折理由の記録** | 何がきっかけで負けたか（トリガー）を残せる |
| **カテゴリ/タグ** | 健康・お金・時間などで分類 |
| **ステータス管理** | 挑戦中 / 達成 / 一時停止 |
| **振り返り・統計** | 過去の挫折回数、最長ストリーク、挑戦履歴 |

## 発展的な機能

| 機能 | 説明 |
|------|------|
| **マイルストーン/実績** | 「3日達成！」「1週間！」「1ヶ月！」などの達成感 |
| **代替行動の提案** | 「タバコの代わりにガムを噛む」など代替メモ |
| **通知/リマインダー** | 危険な時間帯に応援通知 |
