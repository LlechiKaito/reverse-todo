# 逆Todo - 機能アイデア整理

「やめたいことを止めるためのアプリ」

## コア機能（必須級）

| 機能 | 説明 |
|------|------|
| **やめたいこと登録** | 「夜食」「SNSの見すぎ」「喫煙」など、やめたい習慣を登録 |
| **連続日数（ストリーク）** | 我慢できている連続日数を自動カウント |
| **挫折の記録** | 負けてしまった時に「挫折」ボタンを押してリセット |

## あると良さそうな機能

| 機能 | 説明 |
|------|------|
| **やめたい理由の記録** | なぜやめたいか（動機）をメモしておける |
| **挫折理由の記録** | 何がきっかけで負けたか（トリガー）を残せる |
| **カテゴリ/タグ** | 健康・お金・時間などで分類 |
| **ステータス管理** | 挑戦中 / 達成 / 一時停止 |
| **振り返り・統計** | 過去の挫折回数、最長ストリーク、挑戦履歴 |

## 発展的な機能

| 機能 | 説明 |
|------|------|
| **マイルストーン/実績** | 「3日達成！」「1週間！」「1ヶ月！」などの達成感 |
| **代替行動の提案** | 「タバコの代わりにガムを噛む」など代替メモ |
| **通知/リマインダー** | 危険な時間帯に応援通知 |

---

## 利用シナリオ

### シナリオ 1: やめたいことを登録する

**状況**: ユーザーが「夜中のお菓子をやめたい」と決意した
**操作**:
1. アプリを開き「やめたいことを追加」をタップ
2. タイトルに「夜食・お菓子」と入力
3. やめたい理由に「健康診断で体重が増えていた」と記録
4. カテゴリ「健康」を選択
5. 登録完了 → ストリークが「0日目」からスタート

**ゴール**: やめたい習慣と、その動機をセットで記録できる

---

### シナリオ 2: 毎日の我慢を継続する

**状況**: 禁煙チャレンジ5日目。今日も吸わずに1日を終えた
**操作**:
1. アプリを開くと「禁煙」のストリークが「5日連続」と表示されている
2. 日付が変わると自動で「6日目」にカウントアップ
3. （任意）今日の振り返りメモに「会議後に吸いたくなったがガムで乗り切った」と記録

**ゴール**: 日々の努力が数字として可視化され、継続のモチベーションになる

---

### シナリオ 3: 挫折してしまった時

**状況**: SNS断ちに挑戦していたが、3日目に気づいたらTwitterを30分見ていた
**操作**:
1. アプリを開き「SNS断ち」の「挫折した」ボタンを押す
2. 挫折理由を選択/入力：「電車の中で暇だった」
3. 挫折時の感情メモ：「見始めたら止められなかった。後悔している」
4. ストリークが0日にリセットされ、再チャレンジが始まる
5. 過去の記録として「3日間の挑戦 → 挫折」が履歴に残る

**ゴール**: 挫折を責めるのではなく、「何がきっかけだったか」を記録して次に活かせる

---

### シナリオ 4: 過去の挫折パターンを振り返る

**状況**: 夜食をやめるチャレンジで3回挫折した。なぜ繰り返すのか知りたい
**操作**:
1. 「夜食」の詳細画面で統計・履歴を開く
2. 以下の情報が表示される：
   - 挑戦回数: 3回
   - 最長ストリーク: 5日
   - 平均ストリーク: 3日
   - 挫折理由一覧: 「ストレス」「飲み会帰り」「夜更かし」
3. 挫折理由のパターンとして「ストレス起因」が多いことに気づく
4. 代替行動メモに「ストレスを感じたらホットミルクを飲む」と記録

**ゴール**: 挫折データの蓄積によって、自分の弱点・トリガーのパターンを自覚できる

---

### シナリオ 5: マイルストーンを達成して喜ぶ

**状況**: 禁煙チャレンジが7日目に到達した
**操作**:
1. アプリを開くと「1週間達成！」の通知・演出が表示される
2. 達成バッジが付与される（例: 🏅 1週間マスター）
3. 次のマイルストーン「2週間」までのカウントダウンが表示される
4. これまでの歩みを振り返れるタイムラインが見られる

**ゴール**: 節目ごとの達成感を演出し、「もう少し頑張ろう」というモチベーションを生む

---

### シナリオ 6: 複数のやめたいことを同時管理する

**状況**: 「禁煙」「夜食」「SNSの見すぎ」の3つを同時に挑戦中
**操作**:
1. ダッシュボードに3つのチャレンジが一覧表示される
   - 禁煙: 🔥 14日連続
   - 夜食: 🔥 3日連続
   - SNS断ち: 💀 今日リセット（0日）
2. 各チャレンジのステータスが一目でわかる
3. カテゴリ（健康 / 時間）でフィルタリングできる
4. 「SNS断ち」をタップして挫折の詳細を記録する

**ゴール**: 複数の習慣改善を一元管理でき、全体の進捗が見渡せる

---

### シナリオ 7: 一時停止して再開する

**状況**: 旅行中は「夜食やめる」チャレンジを一時停止したい
**操作**:
1. 「夜食」チャレンジのメニューから「一時停止」を選択
2. 理由メモ：「旅行中（3/15-3/18）」
3. ストリークのカウントが一時停止する（リセットはされない）
4. 旅行から帰った後、「再開」ボタンでチャレンジを再開
5. 一時停止期間は履歴に記録される

**ゴール**: やむを得ない事情で中断しても、挫折扱いにならない柔軟な仕組み

---

### シナリオ 8: 危険な時間帯にリマインダーを受け取る

**状況**: 毎晩22時頃に夜食の誘惑が最も強い
**操作**:
1. 「夜食」チャレンジの設定で「危険な時間帯」を 22:00 に設定
2. 22:00にプッシュ通知が届く：
   - 「🔥 夜食を我慢して4日目！ここで負けたらもったいない！」
   - やめたい理由のリマインド：「健康診断で体重が増えていた」
3. 通知をタップすると代替行動の提案が表示される：「ホットミルクを飲む」

**ゴール**: 最も誘惑に負けやすいタイミングで介入し、挫折を防ぐ

---

### シナリオ 9: チャレンジを「達成」として完了する

**状況**: 禁煙を90日間継続できた。もう吸いたいとも思わない
**操作**:
1. 「禁煙」チャレンジのメニューから「達成として完了」を選択
2. 達成コメントを入力：「もう吸いたいと思わなくなった」
3. 最終レポートが表示される：
   - 総チャレンジ期間: 120日（挫折含む）
   - 挫折回数: 2回
   - 最終ストリーク: 90日
4. チャレンジがアーカイブされ、「達成済み」セクションに移動

**ゴール**: 「やめられた」という成功体験を記録し、自信につなげる

---

### シナリオ 10: 初めてアプリを開いたときのオンボーディング

**状況**: アプリをインストールして初めて起動した
**操作**:
1. ウェルカム画面：「やめたいこと、ありませんか？」
2. 代表的な例をサジェスト：「禁煙」「夜食」「SNS」「夜更かし」「衝動買い」
3. 1つ選択（またはカスタム入力）して最初のチャレンジを作成
4. やめたい理由を入力するよう促される
5. 「今日からスタート！」でダッシュボードへ遷移

**ゴール**: 最短ステップで最初のチャレンジを始められ、アプリの価値をすぐに体感できる
